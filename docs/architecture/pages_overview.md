# دليل الصفحات والواجهات الحالية

هذا المستند هو خريطة الواجهات التي يشغّلها التطبيق فعلياً في الـ Closed Beta. كل صفحة لها وظيفة واضحة ضمن المسار الأساسي:

**GitHub → فهم هندسي موثّق → مسودة قابلة للتحرير → مراجعة بشرية → نسخ ومشاركة يدوية.**

لا يَعِد المنتج حالياً بالنشر إلى LinkedIn أو بجلب تحليلات LinkedIn الرسمية. أي حالة أو رقم ظاهر في الواجهة يجب أن يكون ناتجاً عن بيانات حقيقية من التطبيق، أو موسوماً بوضوح كمعاينة/محاكاة.

## قواعد مشتركة لكل صفحة

- توضّح الصفحة أين يوجد المستخدم وما الخطوة التالية المفيدة.
- تعرض حالات التحميل، الفراغ، الخطأ، وعدم الصلاحية بدل ترك مساحة مبهمة.
- تعرض أخطاء العمليات الأساسية داخل الصفحة برسالة مترجمة قابلة للإخفاء وإعادة المحاولة؛ لا تعتمد رحلة التحليل أو الحفظ على رسائل متصفح غير قابلة للوصول.
- تربط كل مسودة بمصدر GitHub وبحزمة الأدلة والادعاءات عندما تكون متاحة.
- لا تعرض أسرار GitHub أو LinkedIn في المتصفح؛ الاتصال الخاص المُدار خادمياً لا يُعاد للعميل.
- تغييرات النص قابلة للحفظ، وتستخدم رقم revision لاكتشاف التعارضات وسجل النسخ.
- المحررات النشطة تحفظ تلقائياً بعد توقف قصير عن الكتابة، مع إبقاء الحفظ اليدوي وسجل النسخ واضحين للمستخدم.
- اللغة واتجاه العرض يدعمان العربية والإنجليزية والألمانية، مع الحفاظ على معنى الحالة لا ترجمة العناوين فقط.

## المسارات والوظيفة

### الصفحة العامة `/`

**المكوّن:** `src/pages/LandingPage.tsx`

تشرح المنتج وحدوده وتدعو إلى تسجيل الدخول أو تجربة العرض العام. يجب أن توضح أن الناتج مسودة موثّقة للمراجعة والنسخ اليدوي، لا ناشراً آلياً لـ LinkedIn. العرض العام نفسه يستخدم fixtures محلية محدودة ولا يطلب GitHub أو Gemini من المتصفح، وتحوّل أخطاء الخدمة إلى رسائل استرداد آمنة لا تكشف تفاصيل backend أو نصوص telemetry حساسة. كما لا تعرض أزرار النسخ نجاحاً إلا بعد نجاح الحافظة فعلياً؛ عند الرفض تظهر إرشادات نسخ يدوية قابلة للفهم.

### معالج البدء بعد تسجيل الدخول

**المكوّن:** `src/pages/OnboardingWizard.tsx`

يجمع الحد الأدنى اللازم للبدء: هوية المستخدم، اللغة، واسم GitHub. يدعم الاستمرار بالمستودعات العامة دون OAuth خاص، وتظهر أخطاء الربط أو حفظ الاختيار داخل الصفحة برسائل آمنة قابلة لإعادة المحاولة، لا برسائل داخلية أو alerts غير مفهومة. نهايته الناجحة تنقل المستخدم إلى المستودعات، وتبقي الإعدادات غير المكتملة واضحة وقابلة للإصلاح.

### المستودعات `/repositories`

**المكوّن:** `src/components/RepositoriesDashboard.tsx`

هذه نقطة الدخول الأساسية للعمل. تعرض مستودعات GitHub العامة المتاحة، البحث والفلترة، وحالة التحليل. قد تقترح الصفحة آخر مستودع محدّث كنقطة بداية فقط؛ حداثة المستودع ليست دليلاً على وجود قصة هندسية أو سبب للتوليد. من هنا يبدأ المستخدم تحليل مستودع أو يفتح تفاصيله؛ الفشل في القراءة يظهر كحالة قابلة لإعادة المحاولة ولا يتحول إلى مسودة بلا مصدر. عند عدم ربط GitHub يمكن تشغيل Demo Mode محلياً لاستكشاف المسار نفسه دون استدعاءات خارجية.

### تفاصيل المستودع `/repositories/:owner/:repo`

**المكوّن:** `src/components/RepoDetails.tsx`

تعرض ملخصاً هندسياً مبنياً على README واللغات والملفات المرشحة والنشاط المتاح، ثم تتيح إنشاء مسودة عبر `GeneratorModal`. يجب أن تظهر حدود التغطية وأي دليل ناقص، وأن يبقى اختيار الفرع/النطاق مرتبطاً بالمصدر الذي ستُبنى عليه المسودة. تُقرأ بيانات التفاصيل عبر endpoint خادمي مع cache قصير لكل مستخدم لمدة خمس دقائق؛ لا يتصل المتصفح بـGitHub مباشرة ولا يحمل credential خاصاً. إذا فشل التحميل تعرض الصفحة سبباً قابلاً للفهم وزر إعادة المحاولة، ولا تعرض صفحة فارغة أو تسمح بالإيحاء بأن المسودة جاهزة.

### المسودات `/drafts`

**المكوّن:** `src/components/DraftsDashboard.tsx`

هذه هي مساحة العمل الموثوقة للمحتوى المولّد. تعرض المسودات مع حالتها، المصادر، الادعاءات، الثقة، مقتطفات الأدلة، والتحذيرات. تحفظ النسخة الأصلية المولّدة كنسخة immutable في سجل النسخ قبل أي تعديل. إذا تعذر تحميلها تعرض حالة خطأ قابلة لإعادة المحاولة بدلاً من الادعاء بأن الحساب فارغ. يمكن للمستخدم تعديل النص، ويُحفظ تلقائياً بعد توقف قصير عن الكتابة مع بقاء الحفظ اليدوي متاحاً، ثم فتح سجل النسخ ومعالجة تعارض الحفظ. تعرض الصفحة عدّاد الأحرف ومعاينة نظيفة للنص وتتيح تصدير TXT محلياً؛ النسخ واللصق هما مخرج المشاركة الحالي ولا يوجد زر نشر مباشر إلى LinkedIn.

### الأتمتة `/automations`

**المكوّن:** `src/components/AutomationsDashboard.tsx`

تدير المشاريع المراقَبة، التواتر، وحالة آخر تشغيل. التشغيل الآلي ينتج مسودة قابلة للمراجعة فقط، ويستخدم lease وrun history وidempotency لمنع التكرار. تعرض الصفحة حالة الإيقاف، الفشل، عدم وجود تغيير جوهري، وحدود الخطة بوضوح؛ تبقى المشاريع الموقوفة ظاهرة حتى يمكن استئنافها، وتتيح حذف مشروع المراقبة وسجل تشغيله مع تأكيد صريح.

### القوالب `/templates`

**المكوّن:** `src/components/TemplatesPanel.tsx`

توفر نقطة انطلاق قابلة لإعادة الاستخدام لأسلوب المسودة. القوالب الجاهزة مكتوبة كأطر أدلة محايدة ولا تفترض إطلاقاً أو أرقام استخدام أو نتائج غير موثقة. تخصيص القالب ثم الضغط على الاستخدام ينشئ مسودة محفوظة وينقل المستخدم إلى `/drafts` للمراجعة؛ لا يوجد callback صامت أو نشر مباشر. القالب لا يثبت صحة الادعاءات ولا يستبدل الأدلة؛ عند استخدامه يجب أن يبقى المصدر والمراجعة البشرية جزءاً من المسار. وإذا تعذر تحميل القوالب المخصصة، يظهر تنبيه واضح مع إبقاء القوالب الجاهزة متاحة بدلاً من عرض حالة فارغة مضللة.
معاينة القالب موسومة صراحةً كمسودة LinkedIn للمراجعة والنسخ اليدوي؛ لا تعرض هوية مستخدم أو دوراً مهنياً أو وقت نشر مختلقاً.

### الإعدادات `/settings`

**المكوّن:** `src/components/SettingsPanel.tsx`

تدير اللغة والملف الشخصي وحالة GitHub المُدارة خادمياً، وتعرض حدود الخصوصية والحساب، مع تأكيد مرئي عند حفظ نطاق الوصول أو فشله وسجل جلسة محلي لا يدّعي أنه سجل سحابي. إذا فشل تحميل إعدادات الحساب نفسها، تتوقف الصفحة في حالة واضحة قابلة لإعادة المحاولة بدلاً من عرض إعدادات افتراضية مضللة. تشمل الصفحة تصدير بيانات الحساب وحذفه عبر مسارات محمية، وروابط الخصوصية والشروط وحدود تكامل LinkedIn. لا تُطلب Personal Access Tokens من المستخدم داخل الواجهة.

### المساعدة والقانون والتعريف بالمنتج

**المكوّنات:** `FloatingHelpWidget`, `HelpGuides`, `LegalModal`, `AboutUsModal`

هذه ليست زخارف منفصلة؛ وظيفتها تقليل سوء الفهم: تشرح معنى الأدلة والثقة، الفرق بين المسودة والنشر، حالة GitHub العامة/الخاصة، وما الذي لا ينفذه المنتج بعد. يجب أن تبقى الرسائل متزامنة مع هذا المستند ومصدر الحقيقة الهندسي.

## واجهات خارج النطاق

لا توجد حالياً صفحة تشغيلية موثوقة لتحليلات LinkedIn الرسمية أو للنشر/الجدولة إلى LinkedIn أو للتفاعل مع الجمهور. أي مكوّن تاريخي يحمل أسماء مثل `PostsHub` أو `AnalyticsPanel` لا يمثل مسار المنتج الحالي ما لم يُربط صراحةً بمسار فعلي وببيانات موثوقة؛ لا يجوز استخدامه في التوثيق أو اختبارات الرحلة الأساسية كأنه ميزة مكتملة.

### مسارات غير معروفة

المسارات غير الموجودة لا تترك مساحة العمل فارغة. يعرض التطبيق حالة 404 داخلية مترجمة مع إجراء واضح يعيد المستخدم إلى `/repositories`، وتغطيها رحلة المتصفح حتى تبقى كل صفحة قابلة للفهم والاسترداد.

## متطلبات الاختبار والصيانة

- كل صفحة فعلية لها اختبار تفاعل أو smoke coverage يثبت التحميل، الحالة الفارغة، الخطأ، والإجراء الأساسي.
- كل تعديل يغير عقداً مرئياً يجب أن يحدّث الترجمة والتوثيق والاختبار المرتبط به.
- لا تستخدم أمثلة تحليلية أو أرقام تفاعل مولّدة على أنها قياسات LinkedIn حقيقية.
- يبقى `docs/PRODUCT_ENGINEERING_SOURCE_OF_TRUTH.md` المرجع الأعلى عند اختلاف وثيقة تاريخية أو مكوّن قديم معه.
